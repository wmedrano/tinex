# Noto Color Emoji

`NotoColorEmoji.ttf` is the Noto Color Emoji COLRv1 font with emoji compatibility
sequences, renamed for use as an embedded GUI fallback font. It uses vector
COLRv1 color glyphs supported by Vello.

The font and license are from the Google Fonts `googlefonts/noto-emoji` source
at commit `e20cbc2bbec1926686be9f9bee7d1d2cfa1fea0e`:
https://github.com/googlefonts/noto-emoji/tree/e20cbc2bbec1926686be9f9bee7d1d2cfa1fea0e/2D/fonts

The upstream font file is `Noto-COLRv1-emojicompat.ttf`. The font is licensed
under the SIL Open Font License 1.1; see `LICENSE.txt`.
