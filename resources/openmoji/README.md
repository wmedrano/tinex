# OpenMoji

All emojis designed by [OpenMoji](https://openmoji.org/) – the open-source emoji
and icon project. License: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
The license text is included in `LICENSE.txt`.

`OpenMoji.ttf` is the unmodified upstream `OpenMoji-color-glyf_colr_1.ttf`,
renamed for use as an embedded GUI fallback font. It uses vector COLRv1 color
glyphs supported by Vello.
